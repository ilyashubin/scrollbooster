# Contributing

Contributions are welcome!

1. Fork this repository and clone it
2. Use Node.js version from `.nvmrc` and run `corepack enable` once to get the pnpm version pinned in `package.json`
3. Run `pnpm install` to install all dependencies
4. Make your changes in `src`. Build output in `dist` is not committed
5. Quick way to test it is to run `pnpm start` and check the demo and `test/index.html` in your browser
6. Run `pnpm build` to build the package
7. Commit your changes and make PR
